## 📖 A História: O Problema Real

### 💔 A Dor do Cliente

Imagine uma pequena loja de roupas que trabalha há anos no mercado. A proprietária, Maria, enfrenta diariamente os mesmos desafios:

> **"Eu não sei o que está parado na minha loja. Tenho produtos que não vendem há meses ocupando espaço e capital. Quando percebo que algo está acabando, já é tarde demais e perco vendas. Não consigo identificar quais produtos me dão mais lucro para focar neles."**

**Os problemas eram claros:**

- 📦 **Capital parado**: Produtos sem movimentação há meses, ocupando espaço e dinheiro
- 🚨 **Estoque zerado**: Descobria que faltava produto apenas quando o cliente perguntava
- 💰 **Lucro invisível**: Não sabia quais produtos geravam mais margem de lucro
- 📊 **Decisões no escuro**: Tomava decisões de compra baseadas em "achismo", não em dados
- ⏰ **Tempo perdido**: Passava horas fazendo inventário manual em planilhas

**O resultado?** Perda de vendas, capital imobilizado e decisões baseadas em intuição, não em dados.

---

## ✨ A Solução: SmartStock

### 🎯 O Que Implementamos

Criamos o **SmartStock** - um sistema completo que transforma o controle de estoque em uma ferramenta estratégica de gestão.

#### 🧠 Inteligência Automática

**1. Sistema de Alertas Inteligente**
- ⚠️ **Alerta de Estoque Mínimo**: Avisa automaticamente quando um produto está abaixo do estoque mínimo
- 📦 **Produtos Parados**: Identifica produtos sem movimentação há mais de 30 dias
- 💰 **Oportunidades de Lucro**: Destaca produtos com alta margem de lucro para aumentar o estoque
- 🔥 **Alta Demanda**: Identifica produtos que estão vendendo muito

**2. Dashboard Estratégico**
- 📊 **Visão Geral em Tempo Real**: Total de produtos, valor do estoque, produtos críticos
- 📈 **Gráficos Interativos**: Visualização de vendas, distribuição por categoria, tendências
- 🏆 **Rankings Inteligentes**: Produto mais vendido, mais lucrativo, menos vendido
- 📉 **Análise de Categorias**: Valor total por categoria para decisões de compra

**3. Cálculos Automáticos**
- 💵 **Margem de Lucro**: Calcula automaticamente a margem de cada produto
- 🔄 **Giro de Estoque**: Identifica produtos com alta rotatividade
- 💰 **Lucro Total Potencial**: Mostra quanto lucro você pode ter com o estoque atual
- 📊 **Métricas por Produto**: Cada produto tem suas métricas calculadas automaticamente

**4. Histórico Completo**
- 📜 **Rastreabilidade Total**: Toda movimentação é registrada com data, usuário e motivo
- 🔍 **Filtros Avançados**: Busque por produto, data, tipo de movimentação
- 👤 **Auditoria**: Saiba quem fez cada movimentação e quando

**5. Gestão Inteligente**
- 🔍 **Busca Avançada**: Encontre produtos por nome, código ou categoria
- 🏷️ **Categorização**: Organize produtos por categorias para análises segmentadas
- ⚡ **Validações Automáticas**: Impede venda se não houver estoque suficiente
- 📱 **Interface Responsiva**: Funciona perfeitamente em desktop, tablet e mobile

### 🎯 Princípios Arquiteturais Aplicados

#### 1. **Separation of Concerns**
- **Controllers**: Apenas recebem requisições e retornam respostas
- **Services**: Contêm a lógica de negócio pura
- **Database**: Abstração de acesso a dados
- **Utils**: Funções puras e reutilizáveis

#### 2. **Single Responsibility Principle (SRP)**
Cada módulo tem uma única responsabilidade:
- `alertService.ts` → Apenas lógica de alertas
- `dashboardService.ts` → Apenas cálculos de dashboard
- `business.ts` → Apenas regras de negócio (cálculos)

#### 3. **Dependency Inversion**
- Controllers dependem de Services (abstrações)
- Services dependem de Database (abstrações)
- Fácil de mockar para testes

#### 4. **Error Handling Centralizado**
- `errorHandler.ts` → Middleware global de erros
- `AppError` → Classe customizada para erros de negócio
- Validações com Zod em todas as entradas

### 🔄 Fluxo de Dados

```
Frontend (React)
    ↓ HTTP Request
Backend (Express)
    ↓
Middleware (Auth, Validation)
    ↓
Controller (HTTP Handler)
    ↓
Service (Business Logic)
    ↓
Database (PostgreSQL via pg-promise)
    ↓
Response
```

### 📊 Camadas da Aplicação

```
┌─────────────────────────────────────┐
│   Presentation Layer (Controllers)  │  ← Recebe HTTP, valida entrada
├─────────────────────────────────────┤
│   Business Layer (Services)         │  ← Lógica de negócio pura
├─────────────────────────────────────┤
│   Data Layer (Database)            │  ← Acesso a dados
└─────────────────────────────────────┘
```

## 📦 Instalação

### Pré-requisitos
- Node.js 18+ e npm
- PostgreSQL 14+
- Git

### Passo a Passo

1. **Clone o repositório**
```bash
git clone https://github.com/seu-usuario/smartstock.git
cd smartstock
```

2. **Instale as dependências**

O projeto usa **npm workspaces** para gerenciar backend e frontend:
```bash
npm run install:all
```

Isso instala:
- Dependências da raiz (workspace manager)
- Dependências do backend
- Dependências do frontend

3. **Configure o banco de dados**

Crie um arquivo `.env` na pasta `backend`:
```env
DATABASE_URL="postgresql://usuario:senha@localhost:5432/smartstock"
JWT_SECRET="sua-chave-secreta-super-segura"
JWT_EXPIRES_IN="7d"
PORT=3001
NODE_ENV=development
FRONTEND_URL="http://localhost:5173"
```

4. **Execute o setup automático do banco**
```bash
npm run db:setup
```

Este comando vai:
- ✅ Verificar se o banco existe
- ✅ Criar automaticamente se não existir
- ✅ Executar o schema SQL (criar todas as tabelas)

5. **Inicie o servidor**
```bash
npm run dev
```

Isso inicia:
- **Backend**: `http://localhost:3001`
- **Frontend**: `http://localhost:5173`

### 🧪 Executar Testes

```bash
# Backend
cd backend
npm test

# Frontend
cd frontend
npm test
```

## 🧪 Regras de Negócio Implementadas

### 💰 Cálculo de Margem de Lucro
```
Margem = ((Preço Venda - Preço Custo) / Preço Venda) × 100
```
Calculado automaticamente para cada produto. **Testado unitariamente**.

### 📦 Produto Parado
Produto sem movimentação de saída há mais de 30 dias (configurável).  
Sistema identifica e alerta automaticamente.

### 🔄 Giro de Estoque
```
Giro = Quantidade Vendida / Estoque Médio
```
Identifica produtos com alta rotatividade.

### ⚠️ Alerta de Estoque Mínimo
Disparado automaticamente quando `quantidade <= estoque mínimo`.  
Sistema verifica e cria alertas em tempo real.

### 🛡️ Validação de Venda
Impede venda se `quantidade solicitada > quantidade disponível`.  
Protege contra vendas de produtos inexistentes. **Testado**.
